# May Flowers: бот магазина

Один бот на всех, у каждого своё меню:

- **Клиенты** открывают магазин кнопкой «Магазин» прямо в Telegram (это мини-апка, тот же сайт) и получают уведомления по своему заказу: принят, собирают, **фото готового букета**, курьер выехал, доставлен. Через год бот сам напоминает о том же поводе.
- **Студии** получают заявки и ведут их по статусам.
- **Вы (админ)** видите все заказы, фото букетов и управляете студиями.

## Что видит клиент в боте

Внизу чата постоянное меню из кнопок (на русском, английском или армянском, по языку Telegram):

- **💐 Каталог** — выбор повода (день рождения, любовь, спасибо, маме, извинение, премиум, все), дальше карточки букетов с фото, составом и ценой в $ и ֏. Листаются стрелками ◀️ ▶️. Кнопка **«🛒 Заказать»** открывает мини-апку сразу на оформлении этого букета.
- **📦 Мои заказы** — список заказов со статусами и кнопка «Открыть кабинет».
- **🤍 Букет добра**, **ℹ️ Как это работает** — короткие объяснения с кнопкой магазина.
- **📞 Связаться** — клиент пишет вопрос прямо в бот, сообщение приходит вам с его ID. Отвечаете командой `/reply ID текст`, и ответ приходит клиенту от имени бота. Контакт для прямой связи задаётся в `MANAGER_CONTACT`.

Каталог бот берёт из файла `catalog.json` на сайте (обновляет раз в 15 минут), а если сайт недоступен, то из `catalog.json` рядом с ботом. Фото букетов тоже берутся с сайта, поэтому `WEBAPP_URL` должен быть задан.

## Мини-апка для клиентов

1. Задеплойте сайт на хостинг с HTTPS (Netlify и т. п.), например `https://mayflowers.am`.
2. Запустите бота с переменной `WEBAPP_URL=https://mayflowers.am`. Бот сам поставит у себя кнопку меню «Магазин».
3. В коде сайта впишите адрес бота в `ORDER_API.url` (см. «Подключение сайта»). Ключ для мини-апки не нужен: заказ подписывает сам Telegram, бот проверяет подпись.
4. По желанию: в @BotFather → `/newapp` можно сделать прямую ссылку на магазин вида `t.me/ИмяБота/shop`. Её удобно ставить в шапку профиля Маиса и под ролики.

Сайт сам понимает, что открыт внутри Telegram. Подстраивается под тему Telegram (светлую или тёмную), берёт язык и имя клиента из профиля, а кнопки «Корзина» и «Заказать» показывает большой кнопкой Telegram внизу экрана. Демо-вкладки («Студия (бот)», «Сайт / Мини-апка») в Telegram скрыты.

**Личный кабинет** в мини-апке общий для всех устройств клиента и берётся с сервера бота: все заказы со статусами, **фото собранного букета**, «Повторить заказ» в один клик, напоминания (можно удалить) и адресная книга получателей. Вход не нужен: клиента узнаёт Telegram, чужие заказы увидеть нельзя. На обычном сайте вне Telegram кабинет пока хранится в браузере.

Напоминания: если клиент оставил галочку «Напомнить в следующем году», бот напишет ему за 3 дня (`REMIND_DAYS`) и накануне той же даты: «Через 3 дня, 7 ноября, — День рождения. Год назад в этот день вы заказывали букет «Пионовое облако» для мамы», с кнопками «🔁 Повторить тот же букет» и «💐 Выбрать букет». И так каждый год. Время отправки — `REMIND_HOUR` (11:00 по Еревану). Заказы из мини-апки привязываются к Telegram сами; для заказов с сайта на странице «Заказ принят» есть кнопка «🔔 Включить напоминания в Telegram» (ссылка `start=rem_…`).

Оплата пока в демо-режиме. Для настоящей оплаты внутри Telegram есть Telegram Payments (подключается через платёжного провайдера в @BotFather) или переход на страницу оплаты банка (Idram, Ameriabank и т. п.).

## Умный помощник (ИИ)

Включается переменной `ANTHROPIC_API_KEY` (ключ Claude API, отдельное рабочее пространство «MayFlowers» в консоли Anthropic). Без ключа всё работает как раньше: на сайте подбор по ключевым словам, в боте сообщения уходят менеджеру.

- **В боте.** Клиент пишет обычным текстом — отвечает ИИ-консультант: присылает до 3 карточек букетов с фото и кнопкой «🛒 Заказать», может придумать текст открытки. Под ответом кнопка «👩 Позвать человека». ИИ сам передаёт диалог человеку, если просят менеджера, жалуются, спрашивают про оформленный заказ, оплату или нестандартный заказ. Пока диалог у человека (`HUMAN_HOURS`, по умолчанию 6 ч), ИИ молчит, сообщения идут админам с кнопкой «✍️ Ответить». Кнопка «🤖 Вернуть помощника» возвращает ИИ.
- **На сайте и в мини-апке.** Блок «Умный помощник» отправляет запрос на `POST /api/ai`, сервер спрашивает Claude и возвращает букеты из каталога и текст открытки. Ключ в браузер не попадает.
- **Защита баланса.** `AI_USER_DAILY` ответов одному клиенту в сутки (40), `AI_DAILY_CAP` всего в сутки (3000), 15 запросов с сайта за 10 минут с одного адреса.
- Модель — `AI_MODEL` (по умолчанию `claude-haiku-5-5`), рассуждения выключены ради скорости. ИИ советует только букеты из каталога, цены берёт из каталога и не упоминает студии.

## Аудио/видео-открытка по QR-коду

1. Клиент выбирает в оформлении «Аудио или видео поздравление». Если заказ из мини-апки, бот сразу просит записать голосовое, кружок или видео. Если с сайта, на странице «Заказ принят» есть кнопка «Записать в Telegram» — она открывает бота с привязкой к заказу.
2. Запись сохраняется к заказу, до доставки её можно перезаписать. Кнопка «Как это увидит получатель» открывает страницу открытки (просмотр отправителя не считается прочтением).
3. Студия, приняв заказ, получает QR-код картинкой и файлом для печати. Его вкладывают в букет.
4. Получатель сканирует код и попадает на `card.html?c=ТОКЕН` на сайте. Там поздравление и кнопка «Ответить голосом». Отправителю приходит «Получатель открыл ваше поздравление 🤍» и голосовой ответ, если он был.

Доступ к записи даёт только длинный случайный токен. Голосовые перекодируются в M4A (иначе iPhone их не играет), записи кешируются в `data/cards/`. Для QR и перекодирования на сервере нужны `python3-qrcode`, `python3-pil` и `ffmpeg` — `server_install.sh` ставит их сам.

## Как работает заказ

1. Клиент оформляет заказ на сайте. Сайт отправляет его боту.
2. Бот присылает заявку первой свободной студии: букет, фото-референс, оформление (упаковка и лента), текст открытки, повод, «Букет добра», комментарий, дата, время, адрес и сумма выплаты студии. Телефона получателя студия пока не видит.
3. Студия жмёт **«✅ Принять»** или **«❌ Не можем»**. Если студия не ответила за 10 минут или отказалась, заявка уходит следующей студии. Если отказались все, бот пишет вам.
4. После принятия студия видит имя и телефон получателя и ведёт заказ: **«📸 Букет готов»** (присылает фото) → **«🚗 Передан курьеру»** → **«✅ Доставлен»**. Шаги перепрыгнуть нельзя.
5. Вы (админ) получаете каждый новый заказ с контактами заказчика и оплатой, фото каждого собранного букета и каждую смену статуса.

## Запуск за 10 минут

Нужен Python 3.9 или новее. Сторонние библиотеки не нужны.

1. **Создайте бота.** В Telegram откройте @BotFather → `/newbot` → придумайте имя, например `MayFlowersStudioBot`. Скопируйте токен.
2. **Узнайте свой Telegram ID.** Проще всего у @userinfobot. Или запустите бота и напишите ему `/myid`.
3. **Придумайте ключ для сайта**, длинную случайную строку. Это `INTAKE_KEY`.
4. **Запустите:**

```bash
export BOT_TOKEN="123456:ABC..."        # токен от BotFather
export ADMIN_IDS="111111111"            # ваш ID; несколько через запятую
export INTAKE_KEY="длинный-случайный-ключ"
export WEBAPP_URL="https://mayflowers.am"   # адрес сайта, когда он задеплоен
python3 bot.py
```

В логе появится: `@ИмяБота запущен, приём заказов на :8080/api/orders`.

5. **Проверьте.** Напишите боту `/start`, потом `/test`. Тестовый заказ придёт вам и подключённым студиям.

## Подключение студий

1. Напишите боту `/invite Студия Роза`. Бот даст одноразовую ссылку.
2. Отправьте ссылку студии. Флорист открывает её, жмёт «Старт», и студия подключена. Вам придёт уведомление.
3. Если у студии несколько флористов, подключите студию в **общий чат**: добавьте бота в группу студии и отправьте в группе `/start КОД` (код из ссылки после `start=`). Для групп обязательно в @BotFather: `/setprivacy` → выберите бота → `Disable`, иначе бот не увидит фото букета, присланное в группу.

## Админка на кнопках

Напишите боту `/start` с аккаунта админа, и внизу появится меню: **📋 Заказы**, **🏪 Студии**, **➕ Пригласить студию**, **🧪 Тестовый заказ**, **👀 Меню клиента**, **❓ Помощь**. Заказы и студии открываются карточками с кнопками: раздать заново, отменить, фото букета, пауза студии, порядок раздачи, удаление (с подтверждением). На сообщение клиента отвечаете кнопкой «✍️ Ответить». Команды ниже работают по-прежнему.

## Команды админа

| Команда | Что делает |
|---|---|
| `/invite Название` | ссылка-приглашение для новой студии |
| `/studios` | список студий с номерами |
| `/pause 2`, `/resume 2` | временно выключить или включить студию |
| `/priority 2 10` | порядок раздачи: меньше число = студия получает заявки раньше |
| `/remove 2` | удалить студию |
| `/orders` | последние 15 заказов и их статусы |
| `/order MF-1043` | заказ целиком, с фото букета |
| `/retry MF-1043` | заново раздать заказ, который никто не взял |
| `/cancel MF-1043` | отменить заказ (студии придёт «не собирайте») |
| `/test` | тестовый заказ |
| `/reply ID текст` | ответить клиенту, который написал в бот |
| `/menu` | показать себе меню клиента, чтобы проверить его |

Студии видят `/active`, список своих текущих заказов с кнопками. Клиенты видят `/orders`, свои заказы и их статусы.

## Где держать бота

Боту нужен сервер, который работает 24/7. Подойдёт любой из вариантов:

- **VPS** (Hetzner, DigitalOcean, любой армянский хостинг) за $4–6 в месяц. Запуск через `systemd` или `screen`.
- **Railway или Render.** Загрузите папку, задайте переменные окружения, команда запуска `python3 bot.py`.

Чтобы сайт мог отправлять заказы, адрес бота должен быть доступен по HTTPS, например `https://bot.mayflowers.am`. На VPS это делается через Caddy или nginx, на Railway и Render HTTPS даётся сразу.

## Подключение сайта

В коде сайта в самом начале скрипта есть строка:

```js
const ORDER_API={url:'',key:''};
```

Впишите адрес бота и ключ:

```js
const ORDER_API={url:'https://bot.mayflowers.am',key:'длинный-случайный-ключ'};
```

После этого каждый оформленный заказ уходит боту. Пока `url` пустой, сайт ничего не отправляет. Это режим демо, в нём сейчас работает макет.

Чтобы сайт с чужих доменов не слал заказы, укажите в `ALLOWED_ORIGIN` ваш домен, например `https://mayflowers.am`.

**Важно:** пока оплата на сайте в демо-режиме, ключ виден в коде страницы, и теоретически кто-то может прислать фейковый заказ. Когда подключите настоящую оплату, заказ должен уходить боту **с сервера после успешной оплаты** (из вебхука платёжки), а не из браузера. Формат тот же.

## Все настройки

| Переменная | По умолчанию | Что это |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather, обязателен |
| `ADMIN_IDS` | — | Telegram ID админов через запятую |
| `INTAKE_KEY` | — | ключ, с которым сайт присылает заказы; пустой = приём выключен |
| `PORT` | `8080` | порт для приёма заказов |
| `ACCEPT_TIMEOUT` | `600` | сколько секунд студия думает над заявкой |
| `PAYOUT_SHARE` | `0.7` | доля студии от цены букетов, если сайт не прислал сумму выплаты |
| `ALLOWED_ORIGIN` | `*` | с какого домена сайт может слать заказы |
| `DB_PATH` | `mayflowers.db` | файл базы (SQLite) |
| `WEBAPP_URL` | — | адрес сайта для кнопки «Магазин»; пусто = кнопки нет |
| `TZ_OFFSET` | `4` | часовой пояс для напоминаний (Ереван +4) |
| `REMIND_HOUR` | `11` | с какого часа слать напоминания |
| `MANAGER_CONTACT` | — | контакт менеджера для кнопки «Связаться», например `@mayflowers_manager` |

## Формат заказа (для разработчика)

`POST /api/orders`, заголовок `X-Intake-Key: <INTAKE_KEY>`, тело JSON:

```json
{
  "id": "MF-1043",
  "items": [{"name": "Пионовое облако", "qty": 1, "price_usd": 110,
             "composition": "Пионы, пионовидные розы, гортензия",
             "image_url": "https://mayflowers.am/img/b05.jpg"}],
  "total_usd": 113,
  "payout_usd": 77,
  "delivery": {"date": "2026-11-15", "window": "14:00–16:00", "exact_time": ""},
  "recipient": {"name": "Анна", "phone": "+374 91 112233", "address": "ул. Абовяна 12"},
  "sender": {"name": "Арк", "phone": "+374 99 000000", "anonymous": true},
  "occasion": "mom",
  "card": {"type": "text", "text": "Мама, с юбилеем!"},
  "wrapping": {"paper": "Фирменный крафт May Flowers", "ribbon": "Розовая атласная (фирменная)"},
  "kindness": true,
  "comment": "Без лилий",
  "payment": {"method": "Idram", "status": "paid"}
}
```

Обязательны `items`, `recipient.phone`, `recipient.address`, `delivery.date`. `window` может быть `"asap"` (как можно скорее) или `"exact"` (тогда время в `exact_time`). Ответ: `{"ok": true, "id": "MF-1043"}`. Проверка, что сервер жив: `GET /health`.

Кабинет (только из мини-апки, заголовок `X-Telegram-Init-Data`):
`GET /api/me` (заказы, напоминания, получатели), `GET /api/photo/<ID заказа>` (фото букета), `POST /api/reminders/delete` с телом `{"id": 5}`.
