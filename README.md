# MayFlowers by Mais

Цветы с доставкой по Еревану от партнёрских студий.

- `index.html`, `img/`, `vid/` — сайт и Telegram мини-апка (один файл, без сборки). Публикуется через GitHub Pages.
- `bot/` — Telegram-бот: заказы клиентов, раздача студиям, статусы, фото букета, напоминания, личный кабинет. Запуск и настройка: [bot/README.md](bot/README.md). На GitHub Pages бот не работает, ему нужен отдельный сервер.

Подключение сайта к боту: в `index.html` найдите `const ORDER_API={url:'',key:''};` и впишите адрес бота.
